# Security and publication scope

This repository is intentionally documentation-only.

Do not add:
- Production Android source code or backend source code.
- API tokens, passwords, signing keys, keystores, or `.env` files.
- Production hostnames, private API routes, or internal infrastructure details.
- Employee identifiers, call logs, phone numbers, contact lists, or customer records.
- Debug APKs, Gradle caches, local IDE settings, or device-specific files.
- Screenshots containing personal or business-confidential information.

If code or screenshots are added in the future, review them for secrets and personal data before committing. Rotate any credential that may have been exposed in a public repository.
